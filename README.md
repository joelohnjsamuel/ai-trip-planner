# AI Trip Planner

An internship project combining a Python/Django web application with the Gemini API to generate personalised travel itineraries.

## Project Context

Developed during my internship at iGeeks Technologies, Bengaluru, from April to May 2024.

This repository currently documents the project and my contribution. It does not yet contain the original application source code or a live demonstration.

## The Problem

Planning a trip involves bringing together travel preferences and organising them into a useful itinerary. This project explored how a web application could use a generative AI API to assist with that process.

## Technologies

- Python and Django
- Gemini API
- HTML, CSS, JavaScript and Bootstrap
- SQLite

## Application Workflow

1. A user enters travel preferences through the web interface.
2. Django validates and processes the input.
3. The application constructs a prompt and sends a request to Gemini.
4. The API returns generated travel suggestions.
5. The application presents the itinerary to the user.

## Engineering Considerations

- Validate inputs before making API requests.
- Handle failed requests and unexpected responses.
- Review generated content rather than assuming it is accurate.
- Keep API credentials outside publicly shared source code.
- Test frontend and backend interactions together.

These considerations describe the engineering approach and areas to assess; this repository does not claim production deployment or measured performance results.
